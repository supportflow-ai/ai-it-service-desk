# Hồ sơ Sprint 1

Trạng thái: bằng chứng lịch sử theo ngày/SHA của từng hồ sơ. Không dùng nhãn Done, APPROVED, BLOCKED hoặc kết quả kiểm thử cũ để nghiệm thu HEAD hiện tại.

Các thư mục TC-196, TC-199, TC-246, TC-247, TC-260, TC-261, TC-264, TC-277, TC-282 và TC-285 lưu review, manifest và kết quả tại mốc nguồn. Bản nguồn trong TC-264/TC-282 phục vụ truy vết bộ scaffold, không phải chỉ dẫn triển khai tiếp.
